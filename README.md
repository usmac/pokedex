# ⚡ Pokédex

Una página web interactiva inspirada en la **Pokédex de Pokémon**, desarrollada con **HTML, CSS y Bootstrap**.

El proyecto presenta información básica sobre Pokémon, sus características y algunas de sus generaciones, utilizando componentes visuales de Bootstrap para crear una interfaz sencilla, organizada y adaptable a diferentes dispositivos.

## 📖 Descripción

Esta Pokédex tiene como objetivo mostrar información sobre diferentes Pokémon de una manera visual y fácil de consultar.

La página incluye:

* ⚡ Barra de navegación.
* 🔎 Barra de búsqueda visual.
* 🧩 Menú desplegable con los diferentes tipos de Pokémon.
* 📚 Sección informativa sobre Pokémon y la Pokédex.
* 🎴 Tarjetas con información de Pokémon.
* 📱 Diseño responsive mediante Bootstrap.
* 📖 Acordeón con información sobre diferentes generaciones.
* 🎨 Estilos personalizados mediante CSS.

## 🖥️ Vista del proyecto

La página contiene una interfaz basada en una barra de navegación oscura y diferentes secciones de contenido.

Entre los Pokémon mostrados actualmente se encuentran:

* 🔥 **Charmander**
* 🌱 **Bulbasaur**
* 💧 **Squirtle**

También se incluye información sobre las primeras generaciones de Pokémon.

## 🛠️ Tecnologías utilizadas

### HTML5

Se utiliza para crear la estructura y el contenido de la página.

### CSS3

Se utiliza para personalizar el diseño y agregar estilos propios al proyecto.

### Bootstrap 5

Se utiliza para crear componentes y facilitar el diseño responsive.

Componentes utilizados:

* Navbar
* Dropdown
* Cards
* Grid system
* Accordion
* Formulario de búsqueda
* Botones

### Google Fonts

Se utiliza la tipografía **Inter** para mejorar la apariencia visual del sitio.

## 🚀 Instalación y ejecución

No es necesario instalar dependencias para ejecutar el proyecto.

### 1. Clonar el repositorio

```bash
git clone URL-DE-TU-REPOSITORIO
```

### 2. Entrar a la carpeta

```bash
cd Pokedex
```

### 3. Abrir el proyecto

Abre el archivo:

```text
index.html
```

en tu navegador.

También puedes utilizar **Visual Studio Code** junto con la extensión **Live Server** para visualizar los cambios en tiempo real.

## 🌐 Bootstrap

El proyecto utiliza Bootstrap mediante CDN, por lo que se requiere conexión a Internet para cargar correctamente los estilos y componentes de Bootstrap.
